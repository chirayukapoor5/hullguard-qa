# Research and design inputs

Public sources accessed 23 November 2026. Vendor publications describe vendor products and workflows. They provide domain context for the synthetic test design.

| Source | Finding | QA implication and design response |
| --- | --- | --- |
| [NAPA Structural Design](https://www.napa.fi/software-and-services/ship-design/structural-design/) | NAPA describes its 3D product model as the basis for weight, BOM, class drawings and FE meshing. | One source has several consumers. HULLGUARD derives artifacts from one typed model and checks each artifact against that model. |
| [NAPA on structural design consistency](https://www.napa.fi/structural-design-consistency/) | The article explains how detached drawings and analysis representations can diverge after edits. | Test a thickness change with fresh and stale files. Include both revision identity and content checks so a current revision marker alone cannot pass. |
| [NAPA Designer](https://www.napa.fi/software-and-services/ship-design/software/napa-designer/) | Interactive 3D structural modeling supports reviewing geometry and structural weight. | Render the actual exported mesh and join picked component IDs to a manifest. |
| [NAPA Drafting](https://www.napa.fi/software-and-services/ship-design/software/napa-drafting/) | Sections and annotations can be derived from a 3D structure and updated as design progresses. | Validate projected plan geometry, drawing metadata and visible dimension labels. |
| [NAPA Manuals for Ship Design](https://help.napa.fi/design/public/portal/index-main.html) | The portal distinguishes public documents from those requiring NAPAnet credentials. | Keep the model format and fixtures independent and use only public material. |
| [ABS Rules for Building and Classing Marine Vessels, Part 3, January 2022](https://ww2.eagle.org/content/dam/eagle/rules-and-guides/archives/other/1_marinevesselrules_2022/mvr-part-3-jan22.pdf) | Longitudinal and transverse framing are distinct directions. The rules discuss continuity and end connections where longitudinal members meet bulkheads. | Model longitudinal flat bars and a transverse plate as identifiable components. Split the bars at the bulkhead to keep volume disjoint. This is a fixture choice with no connection-strength inference. |
| [IMO Ship Design and Stability](https://www.imo.org/en/ourwork/safety/pages/shipdesignandstability-default.aspx) | Watertight subdivision relates to limiting progressive flooding and maintaining stability after damage. | Use bulkhead as structural terminology. Keep watertightness, stability and damage analysis outside the acceptance criteria. |
| [NIST SI Units of Volume](https://www.nist.gov/pml/owm/si-units-volume) and [NIST Guide to SI, chapter 8](https://www.nist.gov/pml/special-publication-811/nist-guide-si-chapter-8) | Volume is measured in cubic metres and mass density in kg/m³. Applying a length conversion in each axis gives 10⁻⁹ m³ per mm³. | Use explicit SI conversion in the exporter and an independent cubic-millimetre reconciliation in the validator. |
| [FreeCAD documentation repository](https://github.com/FreeCAD/FreeCAD-documentation), [headless usage](https://github.com/FreeCAD/FreeCAD-documentation/blob/main/wiki/Headless_FreeCAD.md) and [mesh export](https://github.com/FreeCAD/FreeCAD-documentation/blob/main/wiki/Export_to_STL_or_OBJ.md) | FreeCAD supports Python scripting and console operation. OBJ mesh coordinates have no intrinsic physical unit. | Define coordinates and units in a HULLGUARD OBJ comment and validate them on re-import. Keep the tested core CAD-independent. |
| [ISTQB CTFL syllabus v4.0.1, 15 September 2024](https://istqb.org/wp-content/uploads/2024/11/ISTQB_CTFL_Syllabus_v4.0.1.pdf) | Boundary analysis, regression testing, exploratory testing and risk-based prioritization are distinct parts of test design. | Separate positive regressions, controlled negative executions and manual exploration. Trace risks to specific test conditions. |
| [Three.js OBJ loading](https://threejs.org/manual/pages/load-obj.html) and [OrbitControls](https://threejs.org/docs/pages/OrbitControls.html) | The loader imports mesh geometry and OrbitControls handles camera navigation. | Load the validated OBJ directly. Keep original dimensions and map the documented Z-up axis through the viewer. |

The example density, part sizes, coordinate origin, supported artifact subset and validation tolerances are project decisions documented in [Domain assumptions](DOMAIN_ASSUMPTIONS.md).
