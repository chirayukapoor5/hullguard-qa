# Optional FreeCAD round trip

The adapter builds one editable `Part::Box` per supported component in `model.FCStd`. FreeCAD exports each component as its own STEP solid, named `part-<component-id>.step`. The prefix protects Windows reserved basenames, and the filename identifies each part without depending on label preservation by a receiving CAD system. The model is a set of positioned solids. The STEP files carry geometry in a common coordinate frame. Editable feature parameters are in FCStd.

Use FreeCAD's console executable with the normal Python virtual environment installed. The wrapper launches a short-lived FreeCAD process and passes a local job file to its built-in Python. It does not import FreeCAD into HULLGUARD's Python core.

```sh
python scripts/freecad.py --freecad "<path-to-FreeCADCmd>" export fixtures/baseline.json build/cad/baseline
python scripts/freecad.py --freecad "<path-to-FreeCADCmd>" export fixtures/thickness_changed.json build/cad/revised
python scripts/freecad.py --freecad "<path-to-FreeCADCmd>" validate fixtures/thickness_changed.json build/cad/baseline
python scripts/verify.py --freecad "<path-to-FreeCADCmd>"
```

The third command returns exit 1 and reports both revision drift and geometry differences. Exit 2 indicates invocation, input or runtime problems. Export to a new directory. The wrapper stages and reconciles its outputs before publishing the directory. The sidecar records canonical revision and SHA-256 of the exported files. Hashes support drift detection. The validator also measures geometry after reopening each file.

The bundled CAD observations are from the official portable Windows FreeCAD **1.1.4** release. Its archive matched the published SHA-256 before use. Default CI exercises the CAD-independent core. Optional FreeCAD integration was executed locally on Windows.

## Checks and evidence

| Scenario | Native FCStd | STEP |
| --- | --- | --- |
| Baseline | Editable parameters 2,000 × 1,000 × 6 mm. Mass inferred from CAD volume 94.2 kg. | Reopened solid volume 12,000,000 mm³. Mass 94.2 kg. |
| Revised | Editable thickness 8 mm and bottom at Z = −8 mm. Plate top remains at Z = 0 mm. | Volume 16,000,000 mm³. Mass 125.6 kg, assembly 250.3052256 kg. |
| Missing STEP | S-04 still present. | Inventory and assembly mass checks identify its absence. |
| Stale bundle | Old box parameters and mass differ from the new reference. | Old dimensions and mass differ. Source hash also fails. |
| Restamped STEP | New native model reconciles. | A current sidecar and matching byte digest cannot hide old P-01 geometry. |
| Real native edit | Script edited height and position in FreeCAD, saved FCStd and reopened it. P-01 measured 125.6 kg. | Untouched STEP still measured 94.2 kg and failed dimensional and physical checks. |

FreeCAD measures valid solid topology, global bounding box, centroid and volume after reopening. HULLGUARD compares those values with the canonical box bounds and decimal reference volume and mass. Three independent fixed values are 12,000,000 mm³, 16,000,000 mm³ and a 31.4 kg delta. CAD-derived mass applies the canonical example density to the measured volume. Density, class approval and material transfer via STEP are outside the verified scope. Native editing of the lower plate's thickness requires setting its Placement Z as well. The browser editor performs both changes in the downloaded model.

The exchange is per component and covers axis-aligned rectangular solids generated by this adapter. General STEP assemblies, STEP feature history, non-box imports, real-vessel geometry and interoperability with commercial ship-design software need separate qualification.

## Research

FreeCAD documents console mode and scripting through its bundled interpreter. Part Boxes expose dimensions and placement. Part supports STEP export and exposes solid topology and bounding properties. Some imported objects are returned by the Python API as a generic Shape wrapper, so the runtime reads centroid from the extracted solid.
